# Authoritative sources — France, universal jurisdiction

The distinctive feature of this skill is that sources fall into **four buckets**,
not two. The difference between "there is a database" and "I can cite it" is
itself a discipline this skill teaches.

## Tier 1 — citable authority

| Source | Covers | Notes |
|---|---|---|
| **Légifrance** (`legifrance.gouv.fr`) | Code pénal, Code de procédure pénale, consolidated statute; Cour de cassation decisions | Each article has a versioned `LEGIARTI` ID; cite the version **in force at the relevant date**. Decisions carry `JURITEXT` IDs. |
| **Judilibre** / `courdecassation.fr` | Cour de cassation case law (open data) | The open database of Court of Cassation rulings; *pourvoi* number + ECLI. |
| **Official court / prosecutor record** | Cour d'assises judgments, *chambre de l'instruction* decisions, PNAT communiqués | For assises judgments often the **only** reliable public account is the prosecutor's or court's own statement. |

## Tier 2 — analysis and tracking (label when used; never the citation of record)

For *existence* and *content* — especially of non-public assises judgments —
these are indispensable, but they are **secondary**:
- **TRIAL International** — the **Universal Jurisdiction Annual Review (UJAR)**
  and **Trial Watch** profiles (the workhorse for who is prosecuted where).
- **International Crimes Database (ICD)** — T.M.C. Asser Institute
  (`internationalcrimesdatabase.org`): curated national jurisprudence.
- **Civitas Maxima / GJRP** — esp. the Liberia cases (Kunti Kamara).
- **FIDH**, **Human Rights Watch**, **ECCHR**, **Global Rights Compliance**,
  **Atlantic Council** (Strategic Litigation), **Open Society Justice
  Initiative**, **Asia Justice Coalition** (UJ in/from Asia).
- Academic commentary (Dalloz, Navacelle, university research centres).

Rule: a Tier-2 source can establish *that* a case exists and *roughly* what it
held; it can **never** be the citation of record for a holding. Pair it with the
Tier-1 record, or state the verification ceiling.

## Context only — real, but not citable

- **Eurojust CICED** (Core International Crimes Evidence Database) — a secure
  repository of **evidence** (videos, testimonies, satellite imagery…)
  submitted voluntarily by national authorities; **non-public**, accessible only
  to competent authorities. Describe it as part of the institutional landscape;
  **never cite it** as a source for a fact in an output.
- **Eurojust Genocide Network** — a practitioners' network; its case database is
  non-public, its public output is reports/strategy. Context, not citation.

## Do NOT cite as authority

- **"People's" / opinion tribunals** — the **Kuala Lumpur War Crimes Tribunal
  (Perdana Global Peace Foundation)**, the **Russell Tribunal**, the
  **Permanent Peoples' Tribunal**. These issue **symbolic** verdicts with no
  legal effect, recognised by no State. They are **not** courts exercising
  universal jurisdiction. Flag and exclude; if mentioned, label clearly as a
  civil-society opinion tribunal.

## Fallback ladder (when the full judgment is not public)

For a French international-crimes citation, work down until you can honestly
state a level:
1. **Légifrance / Judilibre** — for statute and any Cour de cassation decision.
2. **Official court or prosecutor record** — the assises verdict announcement,
   the *acte d'accusation* summary, the PNAT communiqué.
3. **Tier-2 tracker** — TRIAL/UJAR, ICD-Asser, Civitas Maxima, FIDH/HRW — for
   existence + content, **labelled as secondary**.
4. **Stop and state the ceiling** — e.g. *"existence and outcome verified via
   the prosecutor's communiqué and TRIAL/UJAR; the full judgment is not public,
   so paragraph-level content is not verified."*
5. **Ask the user** if a higher level is needed and a copy of the judgment can
   be supplied.

Never silently upgrade the level. "Not publicly available" is a finding, not a
failure.
