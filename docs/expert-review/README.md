# Fiches de relecture experte

One-page review sheets, one per skill, to support a quick (~20 min)
practitioner/doctrinal sanity-check of each skill's load-bearing facts,
dates, case numbers, citation conventions, and "traps" before public
reliance.

These are **quality-assurance aids, not part of the skills themselves**.
Each sheet summarises what the corresponding skill encodes and ends with
a short "à confirmer en priorité" checklist for the reviewer. Facts were
verified against the relevant authoritative sources at authoring time;
the sheets exist precisely so a human expert can confirm them.
