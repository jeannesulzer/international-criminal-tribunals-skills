## 1. Cadre
- Jurisdicción Especial para la Paz — composante judiciaire du SIVJRNR (Acuerdo Final, 24 nov. 2016).
- Base légale : **Acto Legislativo 01 de 2017** ; **Ley Estatutaria 1957 de 2019** ; **Ley 1922 de 2018** ; Reglamento General. Contrôle constitutionnel : **C-674/2017**, **C-080/2018**.

## 4. Pièges porteurs encodés
1. **sanciones propias ≠ impunidad** (débat politique — formulation visée comme neutre/technique).
2. **macrocaso ≠ subcaso** (Caso 03 a plusieurs subcasos).
3. **FARC ≠ FARC-EP** (groupe armé jusqu'en 2017 ; parti ensuite ; disidencias non comparecientes).
4. **Sala de Reconocimiento (émet *autos*) ≠ Sección de Reconocimiento (émet *sentencias*).**
5. Avant sept. 2025 : pas de *sentencias* (seulement autos/providencias/resoluciones).
6. **L'espagnol fait foi** ; traductions anglaises non officielles.
