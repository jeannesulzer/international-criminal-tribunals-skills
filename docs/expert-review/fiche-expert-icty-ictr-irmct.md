# Fiche de relecture experte — Skill ICTY / ICTR / IRMCT

*But : vérification praticien/doctrinale en ~20 min. Merci de cocher / corriger.*

## 1. Cadre
- **ICTY** — TPIY (SC Res. 827, 1993 ; clôture 31 déc. 2017).
- **ICTR** — TPIR (SC Res. 955, 1994 ; clôture 31 déc. 2015).
- **IRMCT / MICT / « le Mécanisme »** — SC Res. 1966 (2010) ; branche Arusha opérationnelle 1 juil. 2012, branche La Haye 1 juil. 2013. Continue les fonctions des deux tribunaux ; a jugé les appels tardifs sous numéros MICT.
- Textes fondateurs : les **trois Statuts** + les **trois RPE** (révision en vigueur à la date de la décision) + **Arrangements transitoires**.

## 3. Pièges porteurs encodés
1. **Transition IT/ICTR → MICT** : un même accusé peut porter un numéro de 1re instance (IT/ICTR) **et** un numéro d'appel MICT — citer le numéro correspondant à la phase.
2. **Mesures de protection** : ne **jamais** identifier un témoin protégé ; préférer les versions publiques expurgées.
